# 🎙️ Voice Lab
### 상황 맞춤형 AI 스피치 분석 및 피드백 웹 서비스

> **음성의 속도, 억양, 발화 습관, 문장 구조를 분석하고  
> 사용 상황에 맞는 스피치 피드백을 제공하는 AI 기반 음성 분석 서비스**

Voice Lab은 사용자가 녹음한 음성을 입력하면 음향적 특성과 발화 구조를 분석하여  
**면접 · 발표 · 일반 대화** 상황에 맞는 정량적인 점수와 개선 피드백을 제공하는 웹 서비스입니다.

단순히 음성을 텍스트로 변환하는 것에 그치지 않고,

**음성 입력 → 오디오 전처리 → 음향 분석 → 음성 인식(STT) → NLP 분석 → 상황별 점수 산출 → 피드백 생성**

의 전체 분석 파이프라인을 구현했습니다.

---

# 📌 1. Project Overview

## 💡 개발 배경

말하기 능력을 향상시키기 위해서는 단순히 자신의 음성을 다시 듣는 것보다  
**말하는 속도, 목소리의 변화, 불필요한 공백, 문장 구성 등을 객관적으로 확인하는 과정**이 필요합니다.

특히 면접과 발표처럼 특정 목적을 가진 말하기에서는 상황에 따라 적절한 말하기 방식이 달라집니다.

예를 들어,

- 면접에서는 지나치게 빠르지 않고 침착하게 말하는 것이 중요하고
- 발표에서는 일정한 속도와 함께 적절한 에너지와 억양이 필요하며
- 일반적인 대화에서는 자연스러운 속도와 적절한 말의 흐름이 중요합니다.

Voice Lab은 이러한 차이를 반영하여 **하나의 고정된 기준으로 음성을 평가하는 것이 아니라 사용자가 선택한 상황에 따라 평가 기준을 변경**하도록 설계했습니다.

---

# 🎯 2. Project Goal

Voice Lab의 목표는 음성 데이터를 여러 관점에서 분석하여 사용자가 자신의 말하기 습관을 객관적으로 확인할 수 있도록 하는 것입니다.

### 주요 목표

- 음성 데이터를 일정한 형식으로 전처리
- 음향적 특성을 정량적으로 분석
- 음성을 텍스트로 변환하여 발화 구조 분석
- 상황에 따라 다른 평가 기준 적용
- 분석 결과를 점수와 피드백으로 제공
- 향후 실시간 또는 반복적인 스피치 코칭 서비스로 확장할 수 있는 기반 마련
